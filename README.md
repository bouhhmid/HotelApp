# 🏨 HotelApp

Application complète de gestion hôtelière, développée avec :
- **Backend :** Spring Boot (Gestion des hôtels, chambres, réservations, paiements Stripe, Keycloak)
- **Frontend :** Angular (interface client et admin avec design inspiré de Booking.com)

## 🚀 Structure du projet
HotelApp/
├── GestionHoteliere-front/ → Frontend Angular 16
└── GestionHotilere/ → Backend Spring Boot 3.2
## ⚙️ Technologies principales
- Java 17 / Spring Boot 3
- Angular 16
- PostgreSQL / Stripe / Gmail SMTP
- Keycloak (authentification et rôles)
- Leaflet.js pour les cartes
- Docker (prévu pour le déploiement)

## 💡 Fonctionnalités
- Gestion complète des hôtels, chambres et services
- Réservation en ligne (client)
- Paiement sécurisé via Stripe
- Tableau de bord administrateur
- Chatbot intelligent (Ollama)
- Notifications et gestion d’emails
- Architecture propre et extensible
